Sobre mim

Sou desenvolvedor Full Stack com foco em construir aplicações que resolvem problemas reais. Trabalho com TypeScript, NestJS, React e Supabase — do banco de dados até a interface do usuário.

Já entreguei sistemas em produção para clientes reais: um CRM jurídico completo com integração WhatsApp, plataformas de agendamento para barbearia e salão de estética. Cada projeto com arquitetura limpa, documentação e boas práticas desde o início.

Estou em busca da primeira oportunidade formal como dev — trazendo na bagagem projetos reais, código organizado e muita vontade de crescer dentro de um time.
